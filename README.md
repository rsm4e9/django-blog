# Django Blog Website

A full-stack blog website developed using Python, Django, Bootstrap, HTML, CSS, and SQLite.

## Features

- User registration, login, and logout
- Authentication and authorization
- Create, read, update, and delete blog posts
- Category management
- Search and category filtering
- Comments
- Image uploads
- Draft and published posts
- Dashboard and user management
- Django Admin integration

## Technologies Used

- Python
- Django
- Bootstrap
- HTML
- CSS
- SQLite
- Git & GitHub

## Project Structure

```text
django-blog/
├── blog_main/
├── blogs/
├── dashboards/
├── templates/

├── manage.py
├── requirements.txt
└── README.md
```

## How to Run

```bash
git clone https://github.com/rsm4e9/django-blog.git
cd django-blog
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```.
